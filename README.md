# ecommerce-DEMO

📌 ecommerce Demo<br>
이 프로젝트는 웹 서비스가 어떻게 움직이는지 직접 만들어보며 익히기 위해 만든 간단한 이커머스 데모 웹입니다.<br>
상품 목록, 상품 상세, 장바구니, 로그인 같은 기본 기능을 Flask로 구현했고, 각 기능이 제대로 동작하는지 확인하기 위해 테스트 케이스도 함께 작성했습니다.<br>
실제 쇼핑몰처럼 복잡하게 구성하지 않고, 예시 데이터를 사용해 흐름을 이해하는 데 집중한 학습용 프로젝트입니다.<br>

🎯 프로젝트 주요 기능<br>
🛒 상품 목록 (/products)<br>
전체 상품 리스트 표시<br>
상품 클릭 시 상세 페이지로 이동<br>

📄 상품 상세 (/product/)<br>
이미지·이름·가격 표시<br>
장바구니 담기<br>

🧺 장바구니 (/cart)<br>
선택한 상품 담기<br>

🔐 로그인<br>
아이디·비밀번호 입력 후 로그인 처리 및 오류 시 안내 메시지 표시<br>
로그인 성공 시 상품 목록 이동<br>

🧪 테스트 케이스 설계 (총 20개)<br>
각 기능이 의도한 대로 동작하는지 확인하기 위해 총 20개의 테스트 케이스를 작성했습니다.<br>
정상 흐름과 오류 상황을 모두 포함했으며, UI 표시, 입력값 검증, 화면 전환 등 기본적인 이커머스 시나리오 중심으로 구성했습니다.<br>

🔍 프로젝트를 통해 배운 점<br>
웹 페이지가 어떤 흐름으로 동작하는지 직접 화면을 구성하면서 이해도를 높일 수 있었습니다.<br>
상품 목록 → 상세 → 장바구니 같은 사용자 흐름(UX) 을 직접 구성해보며 페이지 이동 구조를 익혔습니다.<br>
입력값에 따라 화면이 달라지도록 조건을 설정해보고, 오류 상황에 대한 처리 메시지도 고민해보았습니다.<br>
Git과 GitHub로 작업 내용을 버전 관리하는 습관을 익혔습니다.<br>
직접 작성한 테스트 케이스로 웹 기능을 검증해보며, UI 테스트와 기능 테스트의 차이, 입력 검증의 중요성, 오류 메시지 설계 기준 등을 자연스럽게 학습했습니다.<br>

📌 향후 개선 계획<br>
상품 카드 UI를 조금 더 정리해서 화면이 더 깔끔하게 보이도록 개선해보고 싶습니다.<br>
로그인/회원가입 기능을 확장해서 사용자별로 화면이 달라지는 흐름도 만들어보고 싶습니다.<br>
장바구니에 담긴 상품들의 총 금액이 자동으로 계산되도록 기능을 추가할 계획입니다.<br>
지금은 예시 데이터를 코드 안에 넣어두었는데, JSON이나 간단한 DB로 분리해서 실제 서비스처럼 관리해보고 싶습니다.<br>
Playwright로 간단한 자동화 테스트를 여러 번 실행해보면서 익숙해졌고, 앞으로 더 다양한 시나리오에도 적용해볼 생각입니다.<br>
