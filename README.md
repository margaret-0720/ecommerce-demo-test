# ecommerce-DEMO

📌 Mini-Bank Demo (Flask 기반 금융 데모 웹)<br>
이 프로젝트는 웹 서비스가 어떻게 움직이는지 직접 만들어보며 익히기 위해 만든 간단한 이커머스 데모 웹입니다.
상품 목록, 상품 상세, 장바구니, 로그인 같은 기본 기능을 Flask로 구현했고, 각 기능이 제대로 동작하는지 확인하기 위해 테스트 케이스도 함께 작성했습니다.
실제 쇼핑몰처럼 복잡하게 구성하지 않고, 예시 데이터를 사용해 흐름을 이해하는 데 집중한 학습용 프로젝트입니다.<br>

📁 프로젝트 구조<br>
finance-demo/<br>
├── app.py    <br>           
├── templates/  <br>           
│   └── index.html<br>
├── tests/            <br>     
│   ├── test_balance.py<br>
│   ├── test_deposit.py<br>
│   ├── test_history.py<br>
│   └── test_withdraw.py<br>
└── README.md       <br>      
       
app.py : Flask 서버 및 API 라우트 구현<br>
index.html : 상품 목록 / 상품 상세 / 장바구니 / 로그인으로 이동하는 기본 UI 구성<br>

🔧 개발 환경<br>
Python 3.13<br>
Flask 3.1.2<br>
HTML / CSS / jQuery<br>
macOS (VS Code)<br>

🎯 프로젝트 주요 기능<br>
🛒 상품 목록 (/products)<br>
전체 상품 리스트 표시<br>
상품 클릭 시 상세 페이지로 이동<br>

📄 상품 상세 (/product/)<br>
이미지·이름·가격 표시<br>
장바구니 담기” 기능<br>

🧺 장바구니 (/cart)<br>
선택한 상품 담기<br>
동일 상품 중복 시 수량 증가<br>

🔐 로그인<br>
아이디·비밀번호 입력 후 로그인 처리 및 오류 시 안내 메시지 표시<br>
로그인 성공 시 상품 목록 이동, 로그아웃 시 정보 삭제 후 홈 화면 이동<br>

🧪 테스트 케이스 설계 (총 20개)<br>
각 기능이 의도한 대로 동작하는지 확인하기 위해 총 20개의 테스트 케이스를 작성했습니다.<br>
정상 흐름과 오류 상황을 모두 포함했으며, UI 표시, 입력값 검증, 화면 전환 등 기본적인 이커머스 시나리오 중심으로 구성했습니다.<br>

🚀 실행 방법<br>
1. 저장소 클론<br>git clone https://github.com/margaret-0720/FINANCE-DEMO-2.git<br>
cd finance-demo<br>
2. Flask 설치<br>pip install flask<br>
3. 서버 실행<br>python3 app.py<br>
4. 브라우저 접속<br>http://127.0.0.1:5000<br>
